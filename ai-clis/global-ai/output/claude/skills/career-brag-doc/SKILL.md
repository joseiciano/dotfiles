# Career Doc

1:1s and daily or weekly records have their own skills: `/create-one-on-one`, `/create-manager-one-on-one`, `/create-daily-record` and `/create-weekly-record`. Point the user to the one that fits.

## Steps

1. Read [the brag-doc template](references/brag-doc/template.md) and fill it in. When updating, edit the existing doc instead of starting a new one. Done when every template section is filled or marked empty.
2. Roll up from the weekly records in `~/documents/workspace/workjournal/weekly/` for the review cycle, carrying only performance-review-worthy points. Done when every weekly in the cycle has been read.

## Writing rules

- **Point first.** The first line of each point is direct and brief. Later sentences or sub-bullets add context only if needed.
- **Brief.** Short sentences, one idea each, no jargon. Apply the `bro` skill to keep it easy to digest.
