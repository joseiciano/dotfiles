# Reviewing UI

The review branch of [`../SKILL.md`](../SKILL.md).

1. **Scope**: the files or pattern given as the argument. With none given, ask which files to review.
2. **Read** [web-interface-guidelines.md](web-interface-guidelines.md).
3. **Check** every file in scope against every guideline rule and every principle in `../SKILL.md`. Where the project has no design system, check against the design contract in [visual-direction.md](visual-direction.md); where there is no contract either, report that as the first finding. Done when each file has met each rule.
4. **Report** in the guidelines' Output Format, every finding as `file:line`.
